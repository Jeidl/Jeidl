# 预告片分镜表模板

> Summary: 每一镜都写清"时长 + 停/爆 + 声音"，这样剪辑、声音和 AI 生成都能对着同一张表工作。

## Context
把 timeline-120s 展开成逐镜执行文件。

## 字段说明
| 字段 | 说明 |
|---|---|
| 镜号 | 001 起 |
| 入点 | 时码 mm:ss:ff |
| 时长 | 秒 + 帧（24 fps） |
| 段落 | 冷开场 / 一幕 / 转折① / 二幕 / 呼吸 / 三幕 / 片名 / 按钮 |
| 景别 | ELS / LS / FS / MS / CU / ECU |
| 角度·运镜 | 例："低角度，缓推" |
| 画面 | 一句话描述主体 + 动作 + 环境 |
| 停/爆 | 停 / 爆 / 停→爆 |
| 速度 | 常速 / 升格 x% / ramp |
| 声音 | 音乐段落 + 音效 + 是否 hit |
| 台词 / 字幕卡 | 原文 |
| 转场 | 硬切 / 黑场 n 帧 / 闪白…… |
| 备注 | 素材时码或 AI 提示词编号 |
