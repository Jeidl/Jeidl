# 景别与武侠镜头词汇表

> Summary: 远景给"江湖之大"，全景给"招式完整"，特写给"人心与力道"；12 个招牌镜头可以直接写进分镜。

## Context
写分镜表或 AI 提示词时，从这里挑镜头。

## 景别 × 用途
| 景别 | 武侠用途 | 常在 |
|---|---|---|
| 大远景 / 极远景 ELS | 天地与人；孤独；江湖之大 | 冷开场、第一幕 |
| 远景 LS | 阵势、对峙站位（两人分居画面两端） | 第一、二幕 |
| 全景 FS | **完整招式**（港式动作清晰度的基础） | 第二、三幕 |
| 中景 MS | 交手、对白 | 第二幕 |
| 近景 / 特写 CU | 眼神、表情、情感 | 呼吸点、第三幕的"人的配额" |
| 大特写 / 插入 ECU / Insert | 手握剑柄、指节发白、剑出鞘一寸、脚尖点地、雨从剑锋滴落 | "停"段落、冲击点 |

## 角度
| 角度 | 情绪 |
|---|---|
| 低角度仰拍 | 威压、英雄感、反派登场 |
| 高角度俯拍 | 宿命、被包围、阵法 |
| 顶拍 | 群战阵型、棋局式构图 |
| 过肩 | 对峙、对白 |
| 背影 | 神秘、孤独、身份未揭晓（角色预告开场） |

## 12 个招牌镜头【经验法则；个别有来源】
| # | 镜头 | 用途 / 位置 |
|---|---|---|
| 1 | 极远景中背对镜头静立的侠客（浓雾、竹林或大漠），构图"计白当黑" | 冷开场；参考胡金铨风格的提示词写法【S43】 |
| 2 | 拇指推剑出鞘一寸的大特写 | 转折①、"停→爆"的切点 |
| 3 | 两端对峙：两人分居画面左右，中间留白，落叶或风沙横穿 | 第二幕对决预演 |
| 4 | 三镜轻功：起跳 / 空中 / 落地 | 展示武功；拼接手法见建构式剪辑【S21】 |
| 5 | 兵刃交击特写 + 火花 | 冲击点、配 hit |
| 6 | 屋檐、竹梢、水面上的追逐 | 第二、三幕 |
| 7 | 群敌包围的俯拍 | 第三幕升级 |
| 8 | 收剑入鞘之后对手才倒下（省略） | 按钮或某一组的收尾 |
| 9 | 雨中或雪中的慢镜对决 | 高光慢镜【S30】 |
| 10 | 衣袂、发丝、披风的慢镜 | 呼吸点、角色亮相 |
| 11 | 长镜头里发生在画面边缘的动作 | 艺术向预告；《刺客聂隐娘》预告即以此为特点【S31】 |
| 12 | 正反打的眼神特写 | 对决前的"停" |
