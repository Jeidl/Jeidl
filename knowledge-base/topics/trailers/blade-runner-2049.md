# 《银翼杀手 2049 Blade Runner 2049》预告（2017）

> Summary: 整座城市被橙色浓雾笼罩、对称构图、长交叉淡化：用"单色世界 + 对称"建立辨识度极高的视觉风格。

## 为什么值得学

- 主角到达拉斯维加斯后，**整座城市被橙色浓雾笼罩**，橙色传递警告与危险。原版《银翼杀手》有棕褐色调的段落，但没有这么"橙"。
- StudioBinder 的分析认为，雾不是装饰，它呼应了"人类摧毁了地球环境"的主题。
- 评论描述预告：充满雾的大远景、破败的钢结构、"漫长的交叉淡化"、大量霓虹。

## 关键片段拆解

| 元素 | 手法 | 作用 |
|---|---|---|
| 单色世界 | 一个场景只有一种主色（橙 / 冷蓝） | 每个地点一眼可辨 |
| 对称构图 | 人物居中，建筑左右对称 | 秩序感之下的不安 |
| 长交叉淡化 | 两个镜头缓慢叠化 | 梦境、记忆、时间流逝的质感 |
| 渺小的人 | 巨型雕塑、全息影像旁的单个人物 | 孤独与尺度 |

## 可复用技法

1. **一地一色**：给每个场景指定一种主色，写进提示词。
2. **对称 + 居中**：提示词写 `symmetrical composition, subject centered`。
3. **叠化代替硬切**：在"回忆 / 循环重置"的段落使用。

## 迁移到《明日不来》

| 场景 | 主色 |
|---|---|
| 公寓清晨 | 冷蓝 |
| 街道、广场 | 钠灯琥珀 |
| 地铁 | 冷白荧光 |
| 钟楼内部 | 琥珀逆光 |
| 主题物（怀表丝带、烟花） | 唯一的红 |

循环重置的瞬间（午夜 → 06:00）用 12–24 帧的白闪或叠化。
