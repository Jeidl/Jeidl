# 《明日不来》75 秒分镜表（逐镜头时间码）

> Summary: 参赛主版本的 27 个镜头，每个镜头都有时间码、时长、提示词编号、字卡、声音和台词，以及 30 秒社交前导版和 9:16 竖屏版的改法。

## 读表说明

- **画面**列的编号（如 A1、C3）对应 [镜头提示词库](../prompts/shot-prompt-library.md)。
- **字卡**列的编号对应 [字卡文案库](../prompts/text-card-copy.md) 的主句子阶梯 #1–#5。
- **声音**列的编号：M = 音乐，S = 音效，R / L / K / X = 台词，见 [音乐与音效提示词](../prompts/music-sfx-prompts.md)。
- 全程：画面顶部遮幅里放 AKOOL 小标志；底层铺 M3 悬疑垫底音和 S1 慢滴答。

## 需要生成的镜头（按优先级）

| 优先级 | 编号 | 原因 |
|---|---|---|
| P0 必须完美 | A1、A3、C1、F1、E1、G1 | 钩子、规则、静默、按钮 |
| P1 | B1、C2、C3、C4、C5、D2、D5 | 世界观与核心奇观 |
| P2 可以凑合 | D1、D3、D4、D6、D7、E3、E4、B2、B6、C6、C7、G3 | 只出现 0.4–1.5 秒，快剪会掩盖瑕疵 |

共约 25 个独立镜头。每个镜头按 3–4 个版本估算，约 80–100 次生成。

| 0:18–0:22 | 黑 + 字卡 "TODAY IS DECEMBER 31ST" / "FOR THE 4,018TH TIME" |
| 0:22–0:26 | 日期卡 `12.31` |

## 9:16 竖屏版改法

- 不加 2.39:1 遮幅，AKOOL 标志放在画面顶部安全区内（避开平台 UI）。
- 以人物为中心重新裁切。航拍和大远景（B1、E2）改用 B4 或 E1。
- 字卡字号放大到画面宽度的约 6%。
