# 民乐乐器情绪分工

> Summary: 箫、琴主"意"，琵琶、鼓主"杀"，唢呐主"悲壮"，二胡主"情"；民乐与西洋管弦混合是主流做法。

## Context
选配乐、给作曲人写需求或挑曲库时使用。

## 来源要点
- 港式武侠影视兴起后，配乐常用洞箫、笛子、二胡、古筝等民族乐器；香港洞箫演奏家谭宝硕认为洞箫的音色"淡泊中带侠义气质"【S38】。
- 谭盾的《卧虎藏龙》配乐把中国和声、中国乐器与西方管弦乐融合在一起【S27，Britannica】；伯克利的曲目资料显示其主题由二胡独奏引出【S27】。
- 高潮段落多用大型管弦乐和大鼓【S38，曲库描述】。

## 分工表（"常用情绪"一栏为【经验法则】）
| 乐器 | 常用情绪 | 预告位置 | 写法提示 |
|---|---|---|---|
| 洞箫 / 笛 | 孤独、淡泊中带侠气 | 冷开场、A 段 | 长音、气声、滑音 |
| 古琴 | 隐逸、古意、宿命 | A 段、呼吸点 | 泛音、按音的滑音 |
| 琵琶 | 杀伐、急迫（古曲《十面埋伏》即描写楚汉战事） | B 段 ostinato、C 段 | 轮指、扫弦 |
| 古筝 | 流水、柔美；刮奏可以当 riser | A、B 段 | 快速刮奏、琶音 |
| 二胡 | 悲情、命运 | A 段、情感特写 | 主题旋律 |
| 唢呐 | 悲壮、激昂、送别 | C 段主旋律 | 高音长线 |
| 大鼓 / 战鼓 / 堂鼓 | 战场、高潮 | B、C 段 | 与太鼓式打击叠加 |
| 京剧锣鼓（板鼓、大锣、小锣、铙钹） | 打斗节奏、亮相 | B、C 段、角色亮相 | 见锣鼓经 |
| 编钟 / 磬 | 王朝、庙堂、礼制 | 第一幕世界观 | 单击加长混响 |
| 人声（吟唱、戏腔、低吟） | 史诗、苍凉 | A 段或 C 段顶点 | 无词吟唱最稳妥 |
| 大提琴 | 深情、内省 | A 段、情感线 | 《卧虎藏龙》配乐中马友友的大提琴是代表性音色（常识） |
| 弦乐 / 铜管 / 合唱 / 合成器低频 | 史诗推进、冲击 | B、C 段 | 弦乐 ostinato、铜管 braam、sub |

## 搭配原则【经验法则】
1. 一支预告选 1 件"主角乐器"贯穿首尾（例如箫开场，到 C 段由唢呐接过同一个动机）。
2. 民乐负责"辨识度"，管弦和电子负责"能量"。
3. 弹拨乐的颗粒感很适合卡快切，长音乐器适合"停"。
