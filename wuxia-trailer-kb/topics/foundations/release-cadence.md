# 宣发节奏与版本矩阵

> Summary: 预告通常在上映前约半年开始做，依据的是几小时的粗剪；各版本按节点递进，每版换一个侧重。

## Context
规划多支预告的整体打法，或判断某个时间点该出哪种版本时使用。

## 行业事实
- 国内一位预告片剪辑师在 2012 年的采访中说：预告片通常在影片公映前**半年左右**开始制作，拿到的是 **3–5 小时的粗剪**而不是成片；剪辑节奏讲究"先慢后快"【来源 S36】。
- 宣发上要避免过度曝光造成观众疲劳，完整预告的发布宜与行业活动、数字营销节点同步【来源 S06，可信度 C】。

## 春节档实例
| 影片 | 时间 | 物料 |
|---|---|---|
| 《射雕英雄传：侠之大者》（徐克，2025 春节档） | 2024-12-23 | "高手"版预告 + "出招"版海报 |
|  | 2025-01 | "铁血丹心"特别预告 |
|  | 2025-01-20 | 第二支长预告 |
| 《镖人：风起大漠》（袁和平，2026 春节档） | 2026-01-19 | 定档官宣 + "亮招！"版定档预告 |

来源：S34、S35。

## 通用版本矩阵【经验法则】
| 距上映 | 物料 | 剪辑侧重 |
|---|---|---|
| T-6 至 12 个月 | 概念 / 先导预告 | 世界观、意象、悬念，几乎不露剧情 |
| T-2 至 3 个月 | 定档预告 + 定档海报 | 人物关系 + 核心冲突 + 日期 |
| T-1 至 2 个月 | 角色预告组、动作特辑 | 逐个立人设；"武指 / 动作设计"卖点 |
| T-2 至 4 周 | 主题曲 MV、正式预告 | 情感线 |
| T-1 至 2 周 | 终极预告 | 情感 + 最大奇观，全力释放 |
| 上映后 | 口碑预告、竖版切条 | 观众反应、名场面 |

**原则**：每一版都要有新的"主题词"和至少 30% 未露出过的新镜头，避免重复。
