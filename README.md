# Jeidl

## Coming Never 知识库

为 [AKOOL AI Film Challenge](https://www.akool.com/aifilmchallenge)「Coming Never」赛道（给一部不存在的电影做 30–90 秒预告）准备的知识库。

- **风格**：电影级冷峻写实（诺兰 / 维伦纽瓦 / 芬奇式的悬疑大片质感）
- **故事（主方案）**：《第 47 号证物 EXHIBIT 47》。12 人特警队突袭废弃冷库，只有一人走出来，她说："我们进去的时候，是十三个人。"现场多出来的那台执法记录仪，贴着一张三年前的证物标签。完整故事见 [exhibit-47-story](knowledge-base/topics/concept/exhibit-47-story.md)，人物设定、镜头提示词和 90 秒档分镜表（v2，实际 88 秒）也已完成。
- **备选**：《明日不来 UNTOMORROW》（时间循环）等
- **白模预演**：`previs/` 里是按 AKOOL 场景图搭的 Blender 方块白模和 88 秒动态预演（v2），见 [白模预演](knowledge-base/topics/production/exhibit-47-whitebox-previs.md)。
- **内容**：28 篇预告片拆解（覆盖 30 部作品）、8 篇技法（含元结尾字卡库）、5 篇提示词库、多个备选故事、逐镜头分镜表（主方案 89 秒、备选 75 秒）、14 天制作排期、提交检查清单
