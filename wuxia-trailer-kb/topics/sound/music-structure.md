# 预告配乐结构

> Summary: A 段民乐独奏营造意境 → B 段 ostinato 加鼓逐层推进 → C 段全编制、战鼓、唢呐或合唱 → 最大 hit 接片名。

## Context
预告通常"音乐先行"：先定音乐，再按音乐剪画面。

## 来源要点
- 第一幕稀疏、营造氛围，第二幕加入律动和推进，第三幕全力输出：打击乐、旋律、大 hit 在这里达到顶点【S11、S10】。
- 第二幕的转换放在第一次 build，片名放在最大 hit【S10】。
- hit 告诉观众"这一刻重要"，不要自动套用；三幕只是剪辑地图，应围绕实际故事节拍写音乐，而不是把每支预告硬塞进同一个史诗模板【S10】。
- **spotting 表**：逐条记录时间、画面事件、台词、期望的情绪变化、可能的音乐动作和需要静默的地方【S10】。
- 史诗类混合预告配乐：常见 ostinato 主题加打击乐和铜管、弦乐 ostinato、太鼓式 / 部落鼓、合成器脉冲、risers 和 impacts；标注的速度多集中在 **90–130 BPM**（来自单一曲库的标签，仅作粗略参考）【S39】。
- 商业"中国风史诗"曲目常以琵琶、古筝、钢琴和弦乐琶音打底，后半段加入大型管弦乐和大鼓推向高潮【S38，曲库描述】。
- 评论提醒：近年古装剧配乐越来越偏黏腻的抒情唱腔，"侠味"音乐逐渐退场【S38】。→ 武侠预告要保住"侠气"：骨架用打击和弹拨，少用软绵的流行古风唱腔。

## 武侠三段式写法【经验法则】
| 段 | 时码（对齐 120 秒模板） | 写法 |
|---|---|---|
| 前奏 | 0–10 s | 单音或环境化音色（一句箫、一声古琴泛音） |
| A 段 | 10–35 s | 民乐独奏（箫 / 古琴 / 二胡 / 人声吟唱）+ 低频 drone；自由节拍或慢速 |
| 过渡 | 35–40 s | 拔刀 hit + 静默 |
| B 段 | 40–75 s | ostinato 进入（琵琶轮指、古筝快速拨弦、弦乐跳弓）+ 鼓；每 4 或 8 小节加一层 |
| 呼吸 | 75–82 s | 全部抽空，仅留 pad 或环境声 |
| C 段 | 82–108 s | 全编制 + 战鼓 + 唢呐或合唱主旋律；可转调，或从 half-time 切到 double-time 的加速感 |
| 结尾 | 108–120 s | 最大 hit + sub drop → 片名 → 按钮单音 |

## 常见替代方案
- **主题曲 / 片尾曲改编**：国内预告常用，利于主题曲宣发。
- **戏腔 / 京剧元素**：作为 C 段的"中国味"顶点（参见锣鼓经）。
- **反差配乐**：温柔歌谣或慢版老歌配残酷打斗，适合悲剧向。
