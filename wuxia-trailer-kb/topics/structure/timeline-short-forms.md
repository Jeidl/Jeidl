# 短版本时间轴：60 秒先导、30 秒、15 秒竖版、角色预告

> Summary: 越短越要"最强画面先行"；竖版的前 3 秒决定观众是否划走。

## Context
从主预告衍生短版本，或者单独做社媒物料时使用。时间分配属于【经验法则】。

## 60 秒先导预告（两幕）
| 时码 | 内容 |
|---|---|
| 0–5 s | 钩子：一个意象或一句画外音 |
| 5–25 s | 意象蒙太奇（世界观、人物剪影）+ 一句台词；镜长 2–4 s |
| 25–28 s | 静默或黑场（第一次真空） |
| 28–50 s | 爆发快切，镜长 0.3–1 s，中间插 1–2 个慢镜 |
| 50–55 s | 书法片名 |
| 55–60 s | "敬请期待"或档期 |

## 30 秒 spot
| 时码 | 内容 |
|---|---|
| 0–3 s | 最强画面先行（钩子） |
| 3–12 s | 人物 + 冲突，一句台词 |
| 12–24 s | 动作快切（约 15–20 镜） |
| 24–27 s | 片名 |
| 27–30 s | 日期 / 购票引导 |

## 15 秒竖版（9:16）
| 时码 | 内容 |
|---|---|
| 0–3 s | 最强一击或金句，配大字幕 |
| 3–11 s | "三连招"快切，每镜 0.5–1 s，加一句台词 |
| 11–13 s | 片名 |
| 13–15 s | 日期 / 引导 |

**竖版要点**
- 短视频如果不能在前 3 秒引起兴趣，就会被划走；可以把最有冲突、最让人好奇的片段前置，问自己"如果只能留 3 秒，我留哪一帧？"【来源 S37】。
- 人物保持在画面中央的安全区，上下留出字幕区；竖排书法字天然适合竖屏。
- 横版素材裁成竖版时，用重新构图（跟随主体）代替简单居中裁切；对峙双人镜头可以改成上下分屏。

## 角色预告（30–45 秒 / 人，统一模板）
| 时码 | 内容 |
|---|---|
| 0–5 s | 背影或局部（手、兵器、衣角） |
| 5–15 s | 正脸亮相（定格或慢镜）+ 名号卡（姓名·称号），配单个重击 |
| 15–30 s | 招式展示 3–4 个，展示此人的武功特征 |
| 30–40 s | 一句人物台词 + 定格 + 片名 |

亮相的写法可参考京剧"亮相"配锣鼓重击（见 opera-percussion-rhythm）。一组角色预告应使用同一套模板、同一种片名动效，这样连发时有系列感。
