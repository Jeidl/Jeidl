# 音乐策略：熟悉旋律的陌生化（以及如何避开版权）

> Summary: 预告配乐的五种策略，以及为什么比赛里不能用热门翻唱；用公有领域的《友谊地久天长》做双版本变奏，同时满足"熟悉感"和版权安全。

## 五种配乐策略

| 策略 | 样本 | 原理 |
|---|---|---|
| 慢速 / 童声翻唱 | [社交网络 Creep](../trailers/fincher-cover-song-teasers.md) | 熟悉旋律 × 陌生编曲 = 不安 |
| 反讽老歌 | [小丑 Smile](../trailers/joker-2019-teaser.md)、[消失的爱人 She](../trailers/fincher-cover-song-teasers.md) | 甜美的歌词 × 黑暗的画面 |
| 同旋律双版本 | [我们 Tethered Mix](../trailers/us.md) | 音乐结构 = 剧情结构 |
| 有源音乐变调 | [科洛弗道10号](../trailers/10-cloverfield-lane.md) | 画内音乐坏掉 = 世界坏掉 |
| 经典曲目史诗化 | [沙丘 Eclipse](../trailers/dune-2020.md) | 合唱 + 宏大编曲 |
| 角色同源音乐 | [新蝙蝠侠 Nirvana](../trailers/the-batman-teaser.md) | 主角"在听什么" |

## ⚠️ 版权：比赛里不能用的东西

- **流行歌曲和它们的翻唱**：Creep、Immigrant Song、Smile、Something in the Way 都有版权。翻唱同样需要词曲授权。
- **仍在版权期内的古典 / 现代作品**：例如 Ligeti（2006 年去世）的作品，[哥斯拉](../trailers/godzilla-2014.md)用的《安魂曲》仍受保护；Max Richter 在世（见 [降临](../trailers/arrival.md)）。
- **公有领域的曲子，但别人的录音**：作曲本身进入公有领域，不代表某个乐团的录音也是。**必须用你自己生成或演奏的版本。**
- 赛事规则要求只用自己拥有或获授权的素材，见 [赛事规则](../brief/challenge-rules.md)。

## ✅ 推荐方案：《友谊地久天长 Auld Lang Syne》双版本

《友谊地久天长》是苏格兰传统曲调，Robert Burns 1788 年写下歌词，早已进入公有领域，而且它是**全世界的新年歌**。

| | 版本 A：温暖 | 版本 B：扭曲 |
|---|---|---|
| 出现位置 | 第一幕（06:00 起床、收音机） | 第二幕后半到第三幕 |
| 调性 | 大调 | 小调重新配和声 |
| 编曲 | 八音盒、钢片琴 | 低音拨弦、大提琴固定音型、不协和弦乐、合唱 |
| 速度 | 72 BPM | 72 → 110 BPM |
| 含义 | "新年快乐" | "新年永远不会来" |

**过渡**：版本 A 从收音机里播出（有源音乐），在第二幕结尾减速走调（[科洛弗道10号](../trailers/10-cloverfield-lane.md)手法），然后版本 B 接管成为配乐（[我们](../trailers/us.md)手法）。

**为什么这比翻唱流行歌更好**：观众同样一听就认出来，没有版权风险，而且这首歌本身就是剧情：所有人都在唱这首歌等待新年，新年却永远不来。

## 生成与制作

- 用 AI 音乐工具生成（提示词见 [音乐与音效提示词](../prompts/music-sfx-prompts.md)）。**先读清所用工具的商用许可条款。**
- 也可以自己用 MIDI 打谱，八音盒和钢琴音色都很容易做。
- 歌词同样是公有领域，可以让童声合唱哼唱，或只用前两句。
