# 冷开场与片尾按钮

> Summary: 开头 3–10 秒决定观众是否看下去；片名之后再给 3–8 秒的"按钮"，让人记住。

## Context
写时间轴的第一行和最后一行时使用。

## 冷开场（0–10 秒）四种写法【经验法则】
1. **极静远景**：天地之间一个人，配一个单音（箫、风、铃）。最"武侠"，适合写意风格。
2. **金句先行**：黑场中只有画外音一句。例（自拟）："这一刀，我等了十年。"
3. **动作截断**：一击将落未落时切黑，制造悬念，后文再揭晓。
4. **声音先行**：黑场里先听到拔刀、马蹄或雨声，再见画面（J-cut 思路）。

短视频平台上，前 3 秒必须给出兴趣点或悬念，否则会被划走【来源 S37】。所以竖版优先用第 3、4 种，或者直接以最强画面开场。

## 片尾按钮 / Stinger（片名之后 3–8 秒）
作曲人指南把"按钮"列为第三幕之后的一个短段落【来源 S07】；常见的预告形状以一记最后的 sting 收尾【来源 S48，可信度 C】。

| 按钮类型 | 武侠写法 | 声音 |
|---|---|---|
| 幽默反差 | 大战之后一句冷幽默台词或配角吐槽 | 静音 → 一个轻打击 |
| 最后一击 | 片名后再补一招，一刀定格 | 单个重 hit |
| 反转台词 | 揭示身份或背叛的一句话 | 低频 + 静默 |
| 彩蛋人物 | 神秘高手露半张脸或背影 | 一个 braam 或一声锣 |

定档信息（日期、"敬请期待"）一般和按钮同屏，或紧接其后出现 2–3 秒。
