# 《墨池》（暂定）2 分钟预告 · 分镜与剪辑方案

> 素材：你提供的沈墨舟（枯墨剑）对黎无相（无相剑）墨池之战场景。
> 方法：按 `wuxia-trailer-kb` 知识库的结构、节奏、声音与风格规则改编。以下凡是原文没有写到的外观、音乐、字幕卡，都是建议，可以替换。

## 1. 一句话定位
**墨染混沌，混沌蚀墨**：两种武功互相污染、互相折损，没有干净的胜利。预告卖的是"代价"和"不安"，而不是谁更强。

- 版本：定档 / 正式预告，**120 秒**（`20261108-timeline-120s`），另附 15 秒竖版。
- 路数：写意开场（极静、留白）+ 奇观中段（墨幕、墨蟒、墨龙、水墨画卷、混沌球）+ 清晰可读的交手（`20261108-director-styles` 的"商业混合"策略）。
- 全片**没有台词**：原文无对白，叙事交给画面、声音和 3 张字幕卡（`20261108-dialogue-and-voiceover`：少而精）。

## 2. 剧透边界
按"放出来但不解释"的原则（`20261108-qc-checklist`：不露结局和核心反转）：

| 放进预告 | 不放进预告 |
|---|---|
| 三次引爆与剑身裂纹、双剑折断、黎无相险坠断崖 | 最后错身的结果（谁倒下） |
| 腕上墨痕爬了一寸、墨龙勒紧时墨痕收紧 | 墨痕爬到肘侧、黑墨从无相剑断面渗出 |
| 墨池深处出现灰紫 | 墨印连成线流回墨池 |
| 结尾一滴水"没有合拢"（只给异象，不给解释） | 沈墨舟最后的墨针、垂首不动 |

> 保守版：按钮镜头在凹痕撑开的一瞬就切黑，不展示"没有合拢"。

## 8. 配乐方案（`20261108-music-structure`）
- **沈墨舟动机**：古琴（按音滑音），配毛笔擦纸声。
- **黎无相动机**：琉璃质泛音 + 弓擦镲（"碎镜"感）。
- **A 段**（00:10–00:35）：古琴独奏 + drone，在 010 被琉璃泛音打断。
- **B 段**（00:40–01:15）：**90 BPM**（每拍 16 帧，半拍 8 帧），琵琶轮指 ostinato + 低鼓，每 4 小节加一层；亮相和重击处点缀京剧大锣（`20261108-opera-percussion-rhythm`）。
- **C 段**（01:22–01:48）：战鼓 + 低音铜管 + 人声合唱；071 水墨画卷由人声唱主旋律。
- **音乐也被"污染"**：随剧情推进，古琴动机逐渐被琉璃泛音扭曲、走调；按钮最后一声古琴尾音下滑走调。这是"墨染混沌"在声音上的对应。
- 最后对冲（086–092）只留心跳般的低鼓，逐渐加密成"急急风"式鼓点，最大 hit 后全部静音。
