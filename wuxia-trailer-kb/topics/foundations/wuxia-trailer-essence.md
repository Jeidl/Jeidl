# 武侠预告片的核心气质

> Summary: 武侠预告片卖的是"侠"与"江湖"，不只是打斗；节奏上以静衬动，画面上每一击都要看得清。

## Context
动手剪任何一支武侠预告之前先读这篇。它决定后面所有节奏、镜头、声音选择的"调性"。

## 六条核心原则

1. **卖"侠"不只卖"武"**：人物的道义选择比招式更打动人。《射雕英雄传：侠之大者》的预告以"何为大侠、何为大义"为主题线，而不是单纯展示武打【来源 S34】。
2. **先交代"这是什么江湖"**：门派、恩怨、规矩、地理（大漠、客栈、竹林、孤城）。第一幕要在 20–40 秒内让观众知道世界规则【经验法则，参见 three-act-structure】。
3. **静中蓄势、一瞬爆发**：港式/武侠动作的节奏核心是 pause/burst/pause（停—爆—停），停顿让出招显得更快【来源 S02】。留白调动想象，克制放大动作的流畅感【来源 S43，可信度 C】。
4. **写意 vs 写实，先定路数**：胡金铨"文人武侠"偏写意、张彻偏阳刚写实【来源 S26】。预告片要先确认影片属于哪一路，再决定剪辑速度、色彩和音乐（见 director-styles）。
5. **清晰可读**：Bordwell 指出香港动作片把每个镜头做到"不可能被误读"，再组装成停—爆—停结构【来源 S02】；与之相对，好莱坞动作场面常变成"印象式"的模糊混乱【来源 S04】。预告再快，每一招也要看得懂。
6. **奇观与"以武载道"要平衡**：有学术批评指出过度依赖特效奇观会消解"以武载道"的武侠美学【来源 S34】。→ 高潮蒙太奇里每一组快切至少保留一个"人"的情感镜头（眼神、手、回眸）。

## 武侠预告 vs 一般动作片预告【经验法则】

| 维度 | 一般动作片预告 | 武侠预告 |
|---|---|---|
| 开场 | braam、爆炸、快节奏冷开场 | 极静远景、风声、单件民乐乐器 |
| 打斗呈现 | 碎片化快切，重"冲击感" | 快切中保留招式完整度，有"亮相"定格 |
| 音乐 | 混合管弦 + 合成器 | 民乐独奏 → 管弦 + 战鼓（可混电子） |
| 台词 | 解说剧情 | 格言式金句（江湖、侠、道、恩怨） |
| 字幕卡 | 现代无衬线字体 | 书法、竖排、印章 |
| 色彩 | 青橙对比 | 水墨灰、低饱和 + 主题色点睛 |
| 情绪终点 | 刺激 | 刺激 + 宿命感/悲壮 |
