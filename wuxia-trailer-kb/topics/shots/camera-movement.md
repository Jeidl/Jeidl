# 运镜与动作摄影

> Summary: 运镜要服务于"看清招式"和"传达气质"；写意派偏固定和长镜，写实派偏手持近身。

## Context
写分镜或 AI 提示词时，确定每个镜头怎么动。

## 运镜表【经验法则】
| 运镜 | 情绪 / 功能 | 适合 |
|---|---|---|
| 固定机位 | 古典、凝视、写意 | 侯孝贤式极简：固定视角 + 超长镜头【S31】 |
| 缓推 | 压迫、逼近、内心 | 对峙、主题台词 |
| 缓拉 | 揭示"江湖之大"或包围之势 | 第一幕、群战揭示 |
| 摇 | 跟随飞跃、扫视敌阵 | 轻功、阵势 |
| 侧向跟拍 | 奔跑、追逐、连续招式 | 竹林或屋顶追逐；见胡金铨风格的提示词写法【S43】 |
| 升降 / 摇臂 | 从屋檐升起俯瞰 → 宿命感 | 片名前、第三幕顶点 |
| 环绕 | 对峙张力、内力蓄积 | "停"段落 |
| 手持 | 写实、血性、近身肉搏 | 张彻式、近身搏斗类 |
| 威亚 wire-work | 飘逸轻功 | 程小东以优美的威亚武打著称【S49，镜像百科，可信度 C】 |
| 子弹时间 / 冻结环绕 | 奇观 | 慎用，容易显得廉价或像游戏 |

## 两种传统：长镜 vs 快切
- 胡金铨：快速剪接的打斗与优雅的长镜头交替【S25】；《侠女》竹林戏中树、剑、身体以不连贯的瞬间镜头交替出现【S18】。
- 李安《卧虎藏龙》竹林戏：评论认为它用广角长镜头，走了和胡金铨不同的路【S18】。
- 侯孝贤《刺客聂隐娘》：镜头平均远超一分钟，"每次都拍长镜头"【S31】。

→ 预告剪辑师要按影片流派选择：写意 / 艺术向保留长镜的完整呼吸（预告里可以用 4–8 秒的长镜）；商业动作向以快切为主。

## 高速摄影
慢镜依赖拍摄帧率；《一代宗师》用 1000 fps 的 Phantom 拍雨中慢镜【S30】。详见 speed-ramp-and-slow-motion。
