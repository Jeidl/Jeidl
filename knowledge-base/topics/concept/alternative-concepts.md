# 备选创意（西幻写实 / 玄幻 / 航班悬疑 / 卡通）

> Summary: 四个同样贴合「Coming Never」反讽的备选故事，可在不改三幕结构的前提下替换风格。

## 背景

主方案是 [《明日不来》](untomorrow-concept.md)。下面四个方案都保留同一个核心："某件本该到来的事，永远不会到来"，以及同样的三幕 + 黑屏 + 按钮结构，换风格时可以直接替换。

## B. 西幻写实：《不鸣之钟 THE BELL THAT NEVER TOLLS》

- **Logline**：一个王国的黎明钟已经一千个夜晚没有敲响，太阳也再没升起。敲钟人一个接一个被杀，一名被逐出骑士团的女骑士发现，凶手是想让黑夜永远持续下去的人，而他也许有他的理由。
- **视觉参考**：[临冬城墓穴](../trailers/got-crypts-of-winterfell.md)（烛光中缓慢推进）、[沙丘](../trailers/dune-2020.md)（渺小的人和巨大的世界）。
- **结尾按钮**：上映日期卡写着 "AT DAWN"，然后字卡熄灭，变成 "NEVER"。
- **风险**：盔甲、城堡、马匹的跨镜头一致性，抽卡成本约是写实方案的两倍。

## C. 玄幻写实：《不渡 NO CROSSING》

- **Logline**：冥河上的摆渡人拒绝再渡任何亡魂，阳间开始死者不散、生者不宁。一位不信鬼神的捕快追查摆渡人罢工的原因，却发现自己的名字早已写在船票上。
- **视觉参考**：[黑神话：悟空](../trailers/black-myth-wukong.md)（东方神话的写实质感）。
- **结尾按钮**："彼岸 · 永不抵达"。
- **风险**：国际评委理解门槛高，需要英文字卡把世界观讲清。

## D. 现代悬疑（成本最低）：《永不降落 FLIGHT 0000》

- **Logline**：一架红眼航班已经飞了 19 个小时，窗外始终是同一片云海，乘客每小时少一个。到达屏上的状态从 "DELAYED" 变成了 "NEVER"。
- **优点**：只需要机舱一个主场景，一致性最好控制。
- **结尾按钮**：登机牌上的到达时间是 "--:--"。

## E. 卡通（如果你坚持要卡通风格）

- 只能用**原创角色** + **通用的 1930 年代橡皮管卡通风格**（风格本身不受版权保护），**不能出现**汤姆、杰瑞或任何现有角色。
- 创意：一只卡通猫每天重复同一集动画里的追逐，某天它发现老鼠也"记得"上一集。用卡通的明快反衬存在主义恐怖（参考 [鱿鱼游戏](../trailers/squid-game.md) 的"童趣 × 致命"反差）。
- **风险**：AI 卡通角色一致性差，悬疑感难以建立。只推荐作为《明日不来》里的电视彩蛋。

## 选择建议

| 如果你最在意 | 选 |
|---|---|
| 获奖概率 / 制作可控 | 主方案《明日不来》 |
| 视觉奇观 | B 西幻写实 |
| 华语观众 / 文化辨识度 | C 玄幻写实 |
| 时间很紧（不到 7 天） | D 航班悬疑 |
