# 预告片类型与时长

> Summary: 不同版本预告的时长与任务不同；武侠片每个版本应换一个"主题词"和侧重点。

## Context
开工前先确定版本，因为时长直接决定结构（两幕还是三幕）和镜头数量。

## 类型总表

| 类型 | 英文 | 常见时长 | 主要任务 | 武侠片侧重 |
|---|---|---|---|---|
| 概念 / 先导预告 | Teaser | 30–90 秒 | 制造话题，不剧透 | 世界观意象 + 一招 + 片名 |
| 定档预告 | Release-date trailer | 60–120 秒 | 宣布上映日期 | 主要人物、核心冲突、定档卡 |
| 正式 / 主预告 | Main / theatrical trailer | 120–150 秒 | 全面展示影片 | 完整三幕 |
| 角色预告 | Character trailer | 30–60 秒 / 人 | 立人设 | 亮相、名号、招式、一句台词 |
| 终极预告 | Final trailer | 90–180 秒 | 上映前情绪总爆发 | 情感主题 + 最大奇观 |
| 特辑 | Featurette | 1–5 分钟 | 幕后 / 动作设计 | 武指访谈、动作设计拆解 |
| TV / 网络 spot | TV spot | 15 / 30 / 60 秒 | 投放 | 压缩的三幕 |
| 竖版短视频 | Vertical 9:16 | 15–60 秒 | 抖音 / 快手 / 视频号 | 前 3 秒钩子 |

### 来源与说明
- 2分30秒常被称为院线预告的传统上限，完整预告多在 90–150 秒【来源 S06】。北美长期以 2:30 作为 MPA 惯例（每家片厂每年有少量例外），2014 年美国影院业主协会（NATO）曾提出约 2 分钟的自愿性建议【行业常识，本次检索未逐条核实】。
- 先导预告的时长各来源说法不一（30–60 秒、60–90 秒都有），而且常用两幕结构或非线性、抽象的剪法【来源 S06】。
- 15–30 秒的短 spot 通常仍保留三幕【来源 S06】。
- 国内宣发常把每支预告命名为"××版"：例如《射雕英雄传：侠之大者》先后发布"高手"版预告、"铁血丹心"特别预告和第二支长预告【来源 S34】；《镖人：风起大漠》发布"亮招！"版定档预告【来源 S35】。**版本名本身就是营销钩子**，应与该版的剪辑主题一致。

## 选择版本的决策
1. 只有世界观和少量素材 → 先导（两幕，60 秒内）。
2. 有完整粗剪、要宣布日期 → 定档（三幕，90–120 秒）。
3. 群像戏 → 角色预告组（每人 30–45 秒，统一模板）。
4. 上映前 1–2 周 → 终极预告（情感优先，可以更长）。
