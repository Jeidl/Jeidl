# 转场手法

> Summary: 默认硬切；黑场划分幕次，闪白强调冲击，水墨和刀光只在关键处用，避免显得廉价。

## Context
段落与段落、镜头与字幕卡之间如何连接。

## 转场表【经验法则，个别有来源】
| 转场 | 时长 | 用途 | 注意 |
|---|---|---|---|
| 硬切 | 0 | 默认 | 动作切或冲击点切最有力 |
| 黑场 cut to black | 6–24 帧（0.25–1 s） | 幕间、片名前 | 配静默；预告常见"突然黑场 → 最后一击"【S48】 |
| 闪白 / 闪黑 | 2–4 帧 | 冲击、刀光 | 一段里不超过 2–3 次 |
| 刀光划屏 | 6–12 帧 | 顺着刀刃方向擦除到下一镜 | 方向要和挥刀方向一致 |
| 水墨晕染 | 12–36 帧 | 写意风格、片名显现 | 用多了显得像模板 |
| 匹配剪辑 match cut | 0 | 形状或动作匹配：剑尖→新月、雨滴→血滴、转身→转身 | 第一幕讲世界观时很有效 |
| 声音先行 J-cut / L-cut | 声音提前或延后 6–12 帧 | 让下一场的声音先进来 | 冷开场"声音先行"的同一原理 |
| 叠化 dissolve | 12–48 帧 | 情绪转换、时间流逝 | 有分析指出《卧虎藏龙》预告用了几次慢叠化来标示情绪转换，同时快节奏动作继续【S27，博客，可信度 C】 |
| 定格 freeze frame | 12–48 帧 | 角色亮相 + 名号卡 | 配锣鼓式重击 |
