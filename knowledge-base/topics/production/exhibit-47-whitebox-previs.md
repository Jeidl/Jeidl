# 《第 47 号证物》白模预演（Blender）：6 个场景、23 个机位、遮挡检测与 9 条发现

> Summary: 按 AKOOL 场景图用 Blender 搭的全方块白模：6 个场景各一套（附与场景图对齐的参考机位），每个镜头摆好人物、按 89 秒分镜表的时间码让摄影机走一遍，用射线检测核对谁在画面里、谁被挡住；记录每个镜头的机位、动作时间、可见性结果，以及由此发现并已改进提示词的 9 个问题。

## 背景

AI 生成每个镜头之前，先在白模里把**构图、遮挡、动作时机**定下来。白模只用方块：建筑、货架、汽车、人都是方块拼的，表面不做纹理。

- 场景依据：[6 张 AKOOL 场景图](../prompts/exhibit-47-scene-images.md)。每个场景搭一套，空间比例按图来，不按文字设定来。
- 时间依据：[89 秒分镜表](exhibit-47-shot-list.md)。白模的时间轴就是成片的时间轴。
- 文件都在仓库的 `previs/` 目录里：

| 文件 | 内容 |
|---|---|
| `previs/exhibit47_whitebox.py` | 生成整个白模的脚本。所有尺寸都在开头的 `P` 里，改了重跑即可 |
| `previs/exhibit47_whitebox.blend` | 生成好的 Blender 工程（Blender 5.2 保存；旧版本打不开就在 Blender 里重跑脚本） |
| `previs/compose_animatic.py` | 把各镜头的渲染拼成 89 秒动态预演：字卡、4×3 监控墙、蒙太奇、时间码都在这里画 |
| `previs/out/exhibit47_whitebox_animatic.mp4` | 88 秒白模动态预演 v2（640×360，12 帧/秒渲染，24 帧/秒输出） |
| `previs/out/storyboard.jpg` | 39 行分镜各取一帧的总览图 |
| `previs/out/ref_compare.jpg` | 6 张场景图和对应白模的并排对比 |
| `previs/out/analysis.json` | 每个镜头的可见性检测结果 |
| `previs/scene_refs/` | 6 张场景图 |

## v2：第一次审片后的修改

审片结论：故事核心成立，最需要的是让观众看懂**线索之间的关系**。按优先级改了三件事，其余逐条处理。新的时间码见 [分镜表](exhibit-47-shot-list.md)；总长从 89 秒变成 88 秒。

| 审片意见 | v2 怎么改 | 白模里的结果 |
|---|---|---|
| "多一台摄像机"不够不可能，观众会以为现场原本就有 | 字卡改成 **ONLY 12 CAMERAS WERE ISSUED.** → **ONE CAMERA BELONGED TO A DEAD MAN.** → 证物登记表：`47 BODY CAMERA · UNIT 7-12` 盖红框 **LOST**。不再用 THEM / IT 这种代词 | 三张卡各自独立可读；同一个编号 47 / 7-12 连起旧案和今晚 |
| 诺拉被拖走又出现在问询室，需要控制理解 | C2 只做"抓背心、拉进掩护"，同时门外枪火打在她刚站过的门框上 | 枪火 1:02.3–1:02.6；手抓住后停约 0.75 秒再拉；第一次看像袭击，看完结尾能读成救援 |
| 那只手出现得短、小，观众记不住疤 | C2 让手背的疤朝向镜头、不被诺拉挡住；蒙太奇里放大一次这道疤；I3 让疤一直朝镜头；I4 先看手、再看脸、停住 | 射线检测：C2 里疤可见 1:02.1–1:02.9（约 0.85 秒），身体和头始终 0；I3 疤全程可见 |
| 53 秒的镜面容易被看成通往另一条走廊的开口 | 门加深色钢框和把手；倒影胸前的红色录制灯放大，位置正好在视点高度 | 倒影 0:55.33 开始入镜，0:55.38 红灯出现，0:55.42 完整；之后 0:55.55–0:55.85 倒影才转头 |
| 倒影其实 53.3 秒就出现，不是 53.6 秒 | 用镜面反射检测重新量：v1 时间轴上确实是 53.33。把"揭示点"定在这一刻，转头挪到完全入镜之后 | 见上一行（v2 时间轴整体后移 2 秒） |
| 蒙太奇只是在回顾前面的画面 | 改成"证物复查"：每个重复画面都定格放大一个第一次容易漏掉的细节：标签上的 EXHIBIT 47、手背的疤、倒影胸前的红灯、第 13 格的 UNKNOWN | 节奏从 1.1 秒递减到 0.4 秒，最后硬切 |
| "出现四次"的计数口径 | 明确写成：前三次是人（剪影、倒影、手），第四次是**身份线索**（沃德手上同一道疤） | 分镜表的出场表已改 |
| 第 13 格写着 7-12，像第 12 路重新连上 | 改标 **UNKNOWN** | — |
| 结尾说明卡抢走了反转的余味 | 删掉 3 张说明卡，改进发布文案；结尾改成：沃德的手 → 诺拉抬眼 → 片名 → COMING NEVER → 红点 | 红点闪三下、最后一下亮 1.2 秒，第一次看的人也能注意到 |
| 楼梯间两次 "Twelve" 要听得出 | 声音备注：报数结束后停 0.5 秒，第二个 "Twelve." 要清楚 | 画面不变 |

技术上，脚本用一张时间重映射表（`REMAP`）把 v1 的所有动作时间映射到 v2 的剪辑上，所以每个动作的相对时机不变，只有需要改的镜头单独改了。

## 白模怎么用

**在 Blender 里打开**：

- 时间轴上每个标记都绑定了摄影机，**直接播放时间轴就是剪好的预演**。字卡段落切到一台全黑的摄影机。
- 每个镜头的人物在单独的集合里，例如 `SHOT_10_B2`；只在自己的时间段内出现，其他时间缩成看不见的点。
- `CAM_REF_<场景>` 是和场景图同一个视角的参考机位，用来核对白模和场景图是否对得上。
- 人物头顶有名字标签，只在视口里显示，渲染时隐藏。

**颜色约定**（环境都是灰白色）：

| 颜色 | 角色 |
|---|---|
| 青色 | 诺拉 |
| **橙色** | **第十三人**（一眼就能核对他只出现在 4 个镜头里） |
| 黄色 | 布兰特 |
| 紫色 | 沃德（只能露手） |
| 绿色 | 利奥（三年前，只能露手） |
| 灰色 | 特勤组 |
| 粉色小块 | 手背上的烧伤疤 |
| 红色 | 证物标签、录制灯 |

**命令行**（需要 Blender 4.2 及以上，或 `pip install bpy`）：

```bash
blender -b -P previs/exhibit47_whitebox.py -- --save previs/exhibit47_whitebox.blend --meta previs/out/meta.json --analyze previs/out
```

```bash
blender -b -P previs/exhibit47_whitebox.py -- --render previs/out/frames --step 2 --res 640x360 --samples 6
```

```bash
python3 previs/compose_animatic.py previs/out/meta.json previs/out/frames previs/out/exhibit47_whitebox_animatic.mp4 previs/out/storyboard.jpg
```

## 发现（已据此改了提示词）

1. **B8：倒影进不了画面**。记录仪朝前、人沿门走过时，自己的倒影在 90° 方向，最多擦到画面边缘。必须让佩戴者**经过时转身约 70° 朝向门**。B8 提示词已加"turns his body toward it as he passes"。
2. **O1：广角记录仪拍不到"只有手"**。14 mm 的视角下，举起双手的少年脸一直在画面里。改成"旧款记录仪视角更窄（约 24 mm 等效）、离 1.1 m、上仰约 46°"后，头就出画了。O1 提示词已改，还加了"脸在画面下沿之外的黑暗里"。
3. **I4、I2：单向玻璃会照出沃德**。场景图里单向玻璃正好在诺拉身后，从沃德一侧拍她，玻璃右侧能反射出沃德。两条提示词已加"the dark one-way mirror behind her reflects only darkness"；生成后要专门检查玻璃。
4. **C2：手要从缝里伸出来，疤读不出来**。手只能从高箱堆和托盘之间那道缝伸出，第十三人要背对镜头、手臂侧伸，身体才完全挡住。监控离手约 4 m，疤只有几个像素，**疤的线索只能靠 I3 特写**。C2 提示词已改成"从箱堆和托盘之间的缝里侧伸出来"。
5. **B2：从楼梯顶只看得清一个人**。楼梯直跑 12 级后右转，往下看只有前面 1–2 人清楚，其余转过弯看不到。"一整队人"主要靠报数声音传达；如果想看到更多人，生成时可把相机抬高或让队伍站得更开。第十三人在甩镜头之前完全看不到，符合蒙太奇的要求。
6. **E1：红标签在近端**。场景图把红标签放在离镜头最近的袋子上，所以推镜改成**从远端往近端推**，停在红标签上。E1 提示词已改。
7. **C3：门在 20 m 外，镜头要窄一点**。12 mm 时警车只有画面宽度的 3%，改成 18 mm 后车和下车的人都看得清。C3 提示词已写明机位和距离。
8. **D1：外景图有车辙**。场景图从门口到装卸口有两道车辙，D1 要的是没人踩过的雪。D1 提示词已加"no tyre tracks"；38 m 高度下诺拉约占画面宽度的 1%，正好是"一个很小的人"。
9. **B1：门往里开**。人员门在正面最左端，撞开后向内转约 100°，0.3 秒开到底，后面的人 12.4 秒冲进去。

## 下一步

1. **用白模帧做关键帧**：在 AKOOL 图生图里，每个镜头取白模同一时间点的一帧作构图参考（低相似度），配合场景图和设定图生成关键帧。
2. **检查第十三人**：生成的成片仍要按"橙色只出现 4 次"的标准人工核对。
3. **剪辑节奏**：动态预演里每个镜头的时长和分镜表一致，可以直接配临时音乐，检查节奏和字卡停留时间。
