# 导演 / 流派风格谱系与预告对策

> Summary: 先判断影片属于哪一路，再决定预告的速度、声音和色彩；写意派"留白"，写实派"见血"，奇观派"求速"。

## Context
接手一部片子时，用这张表对号入座，或者混合两种风格。

## 风格表
| 导演 / 动作导演 | 风格特征（来源） | 预告对策【经验法则】 |
|---|---|---|
| 胡金铨 | "文人武侠"，偏写意【S26】；引入京剧武打【S26】；抽格剪接【S24】；快切打斗与优雅长镜交替【S25】 | 意境长镜 + 快闪打斗；民乐和京剧打击；水墨字卡 |
| 张彻 | 阳刚、暴力、写实（与胡金铨对照）【S26】 | 手持近身、重击、血色；鼓和铜管；节奏硬朗 |
| 徐克 | 奇诡、速度；《刀》用竹裂、钢鸣构成声音节奏【S23】；《射雕》气旋、内力外化的特效奇观【S34】 | 高速剪辑 + 奇观 + 强声音设计；注意保留"人" |
| 程小东 | 以优美的威亚武打著称【S49，可信度 C】 | 飞跃、衣袂慢镜；空灵人声 |
| 李安（《卧虎藏龙》） | 情感与东方哲思；竹林戏用广角长镜【S18】；谭盾中西融合配乐【S27】 | 情感线和动作线并行；大提琴或二胡主题；叠化 |
| 张艺谋 | 色彩和构图的诗意（《英雄》色彩分段、《影》水墨灰阶）【S28、S32】 | 按色彩组织段落；大构图；慢镜 |
| 王家卫（《一代宗师》） | 雨中慢镜、高速摄影【S30】 | 慢镜 + 独白 + 弦乐；控制重复 |
| 侯孝贤（《刺客聂隐娘》） | 极简长镜、边缘动作、静止【S31】 | 极少剪辑点、环境声为主、几乎不用 hit |
| 袁和平（《镖人》等） | 实打实的近身搏斗、兵刃交锋、马上厮杀【S35】 | 动作清晰度第一；大漠暖色；节奏凌厉 |

## 混合策略
- **商业大片**（主流）：张艺谋式构图 + 徐克式速度 + 胡金铨式留白开场。
- **艺术片**：侯孝贤式的克制，加一个 2–3 秒的爆发镜头当"钩子"。
- **网络电影 / 短剧**：直接用竖版模板，前 3 秒用最强动作。
