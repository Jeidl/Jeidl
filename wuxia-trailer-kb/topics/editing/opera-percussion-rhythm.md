# 锣鼓经与剪辑点

> Summary: 武侠动作的节奏源自京剧武打；把锣鼓点当成剪辑点，就能剪出"中国味"的节奏。

## Context
想让快切带上戏曲式的顿挫，或者设计角色"亮相"时使用。

## 来源要点
- 早期武打片以京剧和北派功夫为基础；在李小龙之前，港片打斗多带着京剧式的"节拍器"律动【S42，通俗史料，可信度 C】。
- 京剧武打干净利落，观众一眼就能看懂打斗过程，胡金铨把它引入电影是很有远见的做法【S26】。
- Bordwell 把 pause/burst/pause 和邵氏打磨出的戏曲式结构联系在一起【S04】。
- 商用京剧打击乐音色库区分了两类：音高较低的用于非动作场面，音高较高的用于打斗场面【S42，商品描述】。
- 赵如兰（Rulan Chao Pian）等学者研究过锣鼓点在京剧戏剧结构中的作用【S42，档案目录】。

## 类比用法【经验法则；锣鼓点名称为戏曲常识，使用前建议向戏曲音乐人确认】
| 锣鼓概念 | 戏曲中的功能 | 预告中的对应 |
|---|---|---|
| 亮相（常配"四击头"） | 角色出场后定格造型 | 角色亮相镜头：定格 / 慢镜 + 单个重击 + 名号字幕卡 |
| 急急风 | 密集急促，用于开打、奔走 | 第三幕快切段：每拍或每半拍一切 |
| 撕边（锣的轻滚） | 紧张、悬念、惊疑 | 转折点前的 riser / 颤音铺垫 |
| 一锤定音 | 单击收束 | 片名出现前的最后一击 |

## 实操
1. 在现代混合配乐里叠一层板鼓、大锣、小锣、铙钹，节奏型用"急急风"式的密集十六分音符。
2. 角色预告里每个人物亮相都配同一个锣鼓收束音，形成系列识别。
3. 剪辑点优先落在锣、钹的重击上，鼓的密集处用来填快切。
