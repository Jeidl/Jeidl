# 武侠意象库

> Summary: 意象是武侠预告的"词汇"；每个意象自带情绪和声音，选对意象就选对了一半气质。

## Context
构思冷开场、世界观镜头和高光慢镜时，从这里挑环境。

（"代表作品"中未标来源的条目为影片常识。）

## 用法
- 一支预告挑 3–5 个主意象，并贯穿首尾（例如开场的雨在高潮回来），比堆满所有意象更有记忆点。
- 意象与色彩绑定（雨 → 冷蓝黑，大漠 → 暖金），见 color-grading。
