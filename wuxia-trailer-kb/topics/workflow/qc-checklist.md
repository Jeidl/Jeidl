# 武侠预告质检清单

> Summary: 交付前逐项打勾；任何一项不合格都不交付。

## 结构与时长
- [ ] 总时长符合版本规格（院线正式预告不超过 2:30）
- [ ] 前 5–10 秒有钩子
- [ ] 三幕（或两幕）分界清晰，节奏先慢后快
- [ ] 至少有一个"呼吸点"
- [ ] 片名落在最大 hit 上；片名后有按钮或档期

## 节奏与可读性
- [ ] 每个完整招式至少 8–12 帧，看得懂
- [ ] 快切段中穿插了慢镜或静止镜（停—爆—停）
- [ ] 每组快切至少有一个人物情感镜头
- [ ] 慢镜不超过 6 个，且彼此不重复
- [ ] 动作方向、景别交替合理

## 声音
- [ ] 台词清晰（台词 > hit > 音乐）
- [ ] riser 顶点与 hit 对齐
- [ ] 2–4 个真空点，没有"数字死寂"的突兀感
- [ ] hit 有大、中、小三级，没有滥用
- [ ] 响度符合投放平台规范（影院、电视、网络各自要求）

## 画面
- [ ] 全片调色统一，色彩随幕推进
- [ ] 红色只用在关键元素上
- [ ] 竖版重新构图，主体在安全区

## 字幕卡与片名
- [ ] 每张卡 4–10 字，停留时间够读
- [ ] 书法片名有授权；字体有授权
- [ ] 错别字、繁简体、标点检查

## 版权与合规
- [ ] 音乐、音效、字体都已授权
- [ ] 未露出关键剧透（结局、核心反转）
- [ ] 符合当地分级和宣发审核要求

## 多版本
- [ ] 60 / 30 / 15 秒、竖版、角色预告规格齐全
- [ ] 各版本的主题词与版本名一致
