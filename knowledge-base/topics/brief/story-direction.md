# 故事定向：悬疑 + 动作 + 无限流（时间循环）

> Summary: 在打斗 / 武侠 / 无限流中选择"悬疑 + 动作 + 时间循环（无限流）"，以及它为什么同时满足故事分、原创分和 AI 制作的限制。

## 结论

**主类型：悬疑惊悚；动作只做调味；结构钩子：无限流里的"时间循环"。**

具体故事见 [《明日不来 UNTOMORROW》核心创意](../concept/untomorrow-concept.md)。

## 三个方向对比

| 方向 | 优点 | 问题 |
|---|---|---|
| 纯打斗 | 节奏快，好剪 | AI 打斗动作最容易穿帮（肢体扭曲、接触不真实）；缺少"引人思考" |
| 武侠 | 有文化辨识度 | 和写实大片风格冲突；兵器、招式一致性难；国际评委理解门槛高 |
| **无限流 / 时间循环** ✅ | 天然制造悬念和思考；和「Coming Never」同构 | 规则要讲清楚，靠字卡解决 |

## 为什么时间循环是最优解

1. **和赛道名同构（加分项，不是硬性要求）**：Coming Never = 永远不会来的电影；我们的故事 = 永远不会来的明天。预告结尾的上映日期卡也被困在循环里（"01.01"倒回"12.31"），这是原创分（20%）最强的抓手。
2. **天然的"黑屏 + 思考"**：每次循环在午夜归零，正好对应**硬切黑屏**。整部预告把"新年永远不会到来"的那一秒做成全片最安静的黑屏。
3. **把 AI 的弱点变成设定**：AI 视频最大的问题是镜头之间的细微不一致。在循环世界里，"每一轮都有点不一样"是**剧情**。同一个镜头还可以在不同循环里重复使用，省下生成成本。
4. **悬疑和动作都有正当理由**：悬疑来自"谁在杀记得循环的人"，动作来自追凶，而且动作里可以加入"时间倒流"的奇观（倒飞的车、停在空中的子弹），比普通打斗更新鲜。
5. **故事分（30%）好拿**：时间循环的规则一句话就能讲清（"每晚午夜，世界重来"），剩下的时间全部用来升级威胁和留悬念。

## 必须满足的"引人思考"三要素

- **一个反常的规则**：每晚午夜世界重来，只有少数人记得。
- **一个道德反转**：反派说"明天，正是我在保护你们不要面对的东西"。他可能是在救人。
- **一个开放的结尾按钮**：女主从自己口袋里掏出了凶手的怀表。她是凶手吗？还是下一个守时人？
