# 预告片结构：三幕 + 按钮 + 能量曲线

> Summary: 预告的三幕微缩结构（提问 → 升级 → 转折 + 片名 + 按钮）、"永不解决"原则、能量曲线，以及 30 / 60 / 90 秒三种时长的时间分配表。

## 背景

多篇剪辑教程的共识：预告借用电影的三幕结构，但**永远不解决任何问题**。

## 三幕微缩结构

| 幕 | 任务 | 结束时观众应该想 |
|---|---|---|
| 一：提问 | 建立世界和一个"不对劲" | "这是怎么回事？" |
| 二：升级 | 威胁、反派、赌注、奇观 | "她要怎么办？" |
| 三：转折 | 最高潮 → **黑屏** → 片名 → 日期 → **按钮** | "我必须看到结局。" |

**按钮（button）**：片名之后的最后一个镜头、一句台词或一个声音。它是预告的"笑点"或"冷点"，也是观众最可能记住并转述的瞬间。

## 三条铁律

1. **永不解决**：不揭示凶手，不解释规则的来源，不给结局。
2. **能量要有起伏**：如果从头到尾都是高能，就没有任何一段显得高能。
3. **前 3 秒必须有钩子**：社交平台的观众 3 秒内决定是否划走。我们的钩子是怀表的指针开始倒走，或者 Ada 不看就接住掉落的杯子。

## 能量曲线（《明日不来》）

```
能量
 ▲                                   ███
 │                     ██           █████
 │            ▄▄      ████    ▁    ███████
 │    ▂▂▂    ████   ██████   ▁▁   █████████      ▂
 │▁▁▁▁▁▁▁▁▁▁██████▁████████▁▁▁▁▁▁███████████▁▁▁▁▁███▁
 └──────────────────────────────────────────────────► 时间
  规则      尸体   字卡   动作   冻结   倒数   黑屏 片名 按钮
                                静默          静默
```

两次静默（冻结人群、倒数后黑屏）是能量曲线的"谷底"，让后面的峰值更高。

## 时长分配

| 版本 | 第一幕 | 第二幕 | 第三幕（含片名和按钮） | 用途 |
|---|---|---|---|---|
| 30 秒 | 0–8 秒 | 8–20 秒 | 20–30 秒 | 社交媒体前导（最低时长） |
| **75 秒（推荐）** | 0–22 秒 | 22–52 秒 | 52–75 秒 | **参赛主版本** |
| 90 秒 | 0–25 秒 | 25–65 秒 | 65–90 秒 | 时长上限，不建议用满 |

主方案《第 47 号证物》最终用的是 90 秒档（实际 89 秒，留 1 秒余量），见 [分镜表](../production/exhibit-47-shot-list.md)。

为什么推荐 75 秒：有足够的空间放两次静默，又不会在第二幕拖沓；离 90 秒上限留有余量，避免导出时超时。

## 常用"句法"

- **台词 → 重音 → 黑屏 / 字卡**：现代预告的基本单位（见 [盗梦空间](../trailers/inception.md)）。
- **重复三次**：同一句台词或同一个画面出现三次，含义递变（陈述 → 怀疑 → 恐怖）。
- **声先于人**：反派先以画外音出现（见 [黑暗骑士](../trailers/the-dark-knight.md)）。
- **中段喘气**：高潮前放慢一次（见 [禁闭岛](../trailers/shutter-island.md)）。
