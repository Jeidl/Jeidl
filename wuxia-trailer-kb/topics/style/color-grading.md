# 调色与色彩

> Summary: 低饱和、高对比是底色；用一种主题色"点睛"（通常是红）；整支预告的色彩要随幕次推进。

## Context
统一预告调色，或者给 AI 生成素材定风格词时使用。

## 实例【来源】
- **《英雄》**（张艺谋，摄影杜可风）：影片按色彩分段，从红到蓝，再到白和绿【S28】。最常被引用的解读是：红 = 想象、蓝 = 被感知的现实、白 = 真相、绿 = 启悟与和平；但各家解读并不一致，也有影评认为颜色没有固定含义【S28】。
- **《影》**（张艺谋，摄影赵小丁）：以水墨画为基础的黑、灰、白色调，布景和服装都按黑白灰设计，外景选在雨天或阴天拍，以去掉环境里剩下的颜色；画面其实是彩色拍摄，所以肤色和血色仍然显出红【S32】。
- AI 视频提示词里常见的"东方极简"参数：高对比、低饱和、老电影颗粒【S43】。

## 六种方案【经验法则】
| 方案 | 特征 | 适合 |
|---|---|---|
| 水墨灰阶 + 一点红 | 去饱和，只留血、印章、红衣 | 写意、悲剧、权谋 |
| 主题色分章 | 每段一种主色 | 多视角叙事、诗意向 |
| 大漠暖金 | 橙金沙色 + 青天，高反差 | 西部式武侠、押镖、亡命 |
| 竹林冷青 | 青绿、雾气、柔光 | 飘逸、情感 |
| 雨夜冷蓝黑 + 暖灯 | 蓝黑基调 + 橙色点光 | 宿命对决、王家卫式 |
| 自然古典 | 接近自然光，柔和低对比 | 艺术向、侯孝贤式 |

## 预告统一规则【经验法则】
1. 预告素材来自不同场景，要用一个总体 LUT 统一，避免"拼贴感"。
2. 色彩随幕推进：第一幕低饱和、偏冷 → 第三幕对比更高、火光和血色进来。
3. 红色只留给最重要的元素（血、印章、主角红衣、片名印），保持它的冲击力。
4. 字幕卡和片名的颜色从画面主色中取。
