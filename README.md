## Coming Never 知识库

为 [AKOOL AI Film Challenge](https://www.akool.com/aifilmchallenge)「Coming Never」赛道（给一部不存在的电影做 30–90 秒预告）准备的知识库。

- **风格**：电影级冷峻写实（诺兰 / 维伦纽瓦 / 芬奇式的悬疑大片质感）
- **故事**：《明日不来 UNTOMORROW》，一部悬疑 + 动作 + 时间循环的预告。城市被困在 12 月 31 日，每晚午夜重来，有人在猎杀记得循环的人。
- **内容**：28 篇预告片拆解（覆盖 30 部作品）、7 篇技法、5 篇提示词库、75 秒逐镜头分镜表、14 天制作排期、提交检查清单
