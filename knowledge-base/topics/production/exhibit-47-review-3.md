# 《第 47 号证物》第三次审片：逐镜复核与粗剪 v4 的修改

> Summary: 第三次审片的重点从"线索缺失"变成"线索之间的关系、拍摄视角是否可信、动作是否形成因果"。按要求逐镜复核了 v3：每条记"时间码—证据—对观众的影响—改法"，并区分确定错误和创作选择。审片优先的四项（记录仪视角、冷冻间机位连续性、监控墙的时间逻辑、伤疤与沃德的对应）都在 v4 修了：疤的镜头改为同一台监控的回放放大，疤按 I3 描下来合成，方向一致；冷冻间重新生成，不再重打光；监控墙改为带时钟的同步直播；第 13 路换成断线之后的新画面。另做了结尾的两个版本。新增 AKOOL 63 积分。逐帧预告拆解仍做不了（下载不到视频）。

## 背景

- 审的是 v3（85.17 秒）。审片人同样说明了"不能实际听辨"，声音部分是复听清单，不是结论。
- 成片：`previs/clips/roughcut_v4_540p.mp4`（**85.6 秒**，结尾 A）。结尾 A 和 B 的对比：`roughcut_v4_endings_540p.mp4`（33 秒）。时间线和声音落点：`roughcut_v4.timeline.json`、`roughcut_v4.cues.json`。
- v3 和 v4 同一位置的对比图：`previs/clips/review3_v3_vs_v4.jpg`（监控墙、疤、冷冻间两处、第 13 路）。
- 下文"v3 时间"按审片人给的时间，"v4 时间"按新时间线。

## 二、优先的四项

### 1. 记录仪视角

v3 的疤特写是"胸前记录仪俯视自己胸前"，物理上不成立。而且 CCTV 里那只手是从她身后抓的，她胸前的镜头根本拍不到。v4 改为**同一台 CAM 11 的回放放大**：调查人员回放时把画面放大 4 倍，屏显写 `CAM 11 PLAYBACK ZOOM 4X`，画质是放大后的块状和噪点。画面里手从左边的箱子缝伸出来，诺拉转头看着手背上的疤。

### 2. 冷冻间机位连续性

用同一张空房间底图（从抓人帧去掉人物做成）检查每一帧：v4 的进门和拖拽都对得上，比例差在 1–5% 以内。火花不再由模型生成（它会重画整个房间），改为在门框上后期合成 3 帧。

### 3. 监控墙的时间逻辑

| 时刻 | 墙上 | 活着的格子 |
|---|---|---|
| 04:09:12（22.6） | 平静的搜索：门口、黑暗走廊、两处不同的塑料门帘、闪光后的走廊、楼梯（诺拉） | 6 路，3 秒内 FEED 03、02 断线 |
| 05:02:55（47.9） | 枪火、毒气、闪光、对峙 | 4 路，1 秒内断 3 路 |
| 05:12:06（53.9） | 只剩诺拉那路，0.6 秒后断 | 1 路 |
| 05:12:07–（54.9） | 全部 SIGNAL LOST，时钟还在走，全静音 1.5 秒 | 0 |
| 05:12:10–（56.4） | 中间出现第 13 路，有自己的时钟 | — |

### 4. 伤疤与沃德

- 用 I3 原图把沃德手背上的疤描成 8 个点，加上靠近手腕的小钩。
- 把 I3 那块皮肤（含真实的疤）旋转 180° 放进手套的裂口。旋转不是镜像，所以仍是右手；在一只手指朝右的手上，"手腕 → 食指根部"仍是同一个"/"方向，和 I3 一致，观众不用在脑子里转。
- 手套上原来那个整齐的圆洞填上布料，改成一道顺着疤撕开、两头收尖、边缘起毛的裂口。
- 脚本：`previs/keyframes/tools/scar_composite.py`。
- 沃德的身份：审讯室的屏显现在写着 `SUBJECT N. KADE (7-12)` 和 `INTERVIEWER INSP. E. WARD`（I1 和 I3 都有），所以结尾那只手属于一个已经被介绍过的人。诺拉是谁也一样，第一次出现就写着她是 7-12。

## 教训

1. **先问"这台设备能不能拍到这个画面"**：胸前的镜头拍不到自己胸前，也拍不到背后抓她的手。换成同一台监控的回放放大，设备、视角和"她看见了"都成立。
2. **提示词里的一个火花能让模型重画整个房间**。固定机位的镜头里，光效、火花、爆炸都放到后期合成。
3. **监控墙是一个时刻，不是素材拼贴**：加一个走动的时钟，所有格子就必须是同一时刻的画面，这条规则会自动淘汰不合适的素材。
4. **对口型先测嘴动**：嘴部区域的帧差能找出说话的时段，台词按这个剪，不够的部分宁可删掉。
5. **线索要求"同一个"，就直接用同一个**：疤从 I3 描下来、贴回去，比让模型"画一道一样的疤"可靠；方向用旋转（不是镜像）保持一致。
6. **声音的含义要全片一致**：提示音只表示"开始录制"。
