# 留白与悬念营销：少给，让观众自己去找

> Summary: 八种"少给信息"的手法（只给日期、密码彩蛋、ARG、倒计时、突袭发布、藏起怪物、合法误导、线下装置），以及如何用它们拉高评分里的"想看度"。

## 背景

评分里 15% 是"I'd watch that"（想看度）。最能提高想看度的不是"给更多"，而是**精确地少给**：让观众产生一个具体的问题，并相信答案就在电影里。

## 八种手法

| 手法 | 样本 | 我们怎么用 |
|---|---|---|
| 只给日期，不给片名 | [科洛弗档案](../trailers/cloverfield-teaser.md) | 15 秒社交前导只出 "12.31" |
| 密码彩蛋 | [长腿](../trailers/longlegs-teasers.md) | 证据墙上唯一一张 "01.01" 的照片 |
| ARG / 网站 | [黑暗骑士](../trailers/the-dark-knight.md) | 可选：在视频简介里留一个"醒着的人"的联系电话或网址 |
| 倒计时 | [奥本海默](../trailers/oppenheimer-teaser.md) | 倒数到 1 就黑屏，新年永远不来 |
| 突袭发布 | [科洛弗道10号](../trailers/10-cloverfield-lane.md) | 正式预告之前不发任何预热 |
| 藏起怪物 | [不](../trailers/nope.md) | 守时人永不露脸 |
| 合法误导 | [临冬城墓穴](../trailers/got-crypts-of-winterfell.md) | Ada 的照片出现在受害者那一栏 |
| 几乎不用正片画面 | [星际穿越](../trailers/interstellar-teaser.md) | 30 秒前导只用独白 + 空镜 |
| 线下 / 社交装置 | [鱿鱼游戏](../trailers/squid-game.md) | 话题："如果明天永远不来，你今天做什么？" |

## 我们要留下的三个问题

1. **守时人是谁？**（不露脸）
2. **明天到底有什么？**（"Tomorrow is what I'm saving you from."）
3. **Ada 为什么会有那块怀表？**（结尾按钮）

三个问题都**不回答**。只要评论区有人在争论答案，想看度就到手了。

## 发布建议（结合赛事规则）

- 正式预告发在 YouTube（横屏 16:9），同时剪一个 9:16 的竖屏版发 TikTok / Instagram。规则要求至少在一个平台公开。
- 标题建议：`UNTOMORROW — Official Trailer (Coming Never) | #AKOOLFilmChallenge`
- 简介第一行放一句钩子："Every midnight, the world starts over. Only some of us remember."
- 置顶评论问观众一个问题："Who do you think the Timekeeper is?"
