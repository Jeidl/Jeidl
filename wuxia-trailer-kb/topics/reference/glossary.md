# 中英术语表

> Summary: 剪辑、动作、声音、分镜、宣发五类术语的中英对照。

## 预告结构与宣发
| 中文 | English | 释义 |
|---|---|---|
| 预告片 | trailer | 最早放在正片之后，因此叫 trailer |
| 先导预告 | teaser | 短、不剧透、制造话题 |
| 定档预告 | release-date trailer | 宣布上映日期的版本 |
| 终极预告 | final trailer | 上映前的最后一支主预告 |
| 角色预告 | character trailer | 单个角色的人设短片 |
| 特辑 | featurette | 幕后、动作设计等专题 |
| 冷开场 | cold open | Logo 前后直接进入的钩子 |
| 按钮 / 彩蛋 | button / stinger | 片名后的最后一拍 |
| 字幕卡 | title card | 画面间的文字卡 |
| 三幕结构 | three-act structure | 铺垫—升级—高潮 |

## 剪辑
| 中文 | English | 释义 |
|---|---|---|
| 平均镜长 | ASL (average shot length) | 时长 ÷ 镜头数 |
| 卡点 | cutting to the beat | 剪辑点对齐音乐节拍 |
| 动作切 | cut on action | 在动作中段切换角度 |
| 冲击点切 | cut on impact | 在打击接触帧切换 |
| 重叠剪辑 | overlapping action | 同一动作多角度重复 |
| 抽格 | frame skipping | 去掉部分帧让动作更快 |
| 建构式剪辑 | constructive editing | 用剪辑拼出实拍不存在的动作 |
| 停—爆—停 | pause / burst / pause | Bordwell 对港式动作节奏的概括 |
| 表现性放大 | expressive amplification | 用技法放大动作的情绪力量 |
| 分段拍摄 | segment shooting | 按机位分段设计和拍摄招式 |
| 省略 | ellipsis | 只给起因和结果 |
| 变速 | speed ramp | 同一镜头内改变播放速度 |
| 升格 / 降格 | overcrank / undercrank | 高帧率拍摄得慢镜 / 低帧率得快镜 |
| 黑场 | cut to black | 切到黑画面 |
| 闪白 | white flash | 2–4 帧白画面 |
| 匹配剪辑 | match cut | 形状或动作相似的镜头相接 |
| 声音先行 / 后延 | J-cut / L-cut | 声音早于或晚于画面切换 |
| 叠化 | dissolve | 两镜交叠过渡 |
| 拉片 | shot-by-shot breakdown | 逐镜拆解分析 |
| 粗剪 / 精剪 | rough cut / fine cut | — |

|---|---|---|
| 景别 | shot size | ELS / LS / FS / MS / CU / ECU |
| 插入镜头 | insert | 局部特写 |
| 正反打 | shot / reverse shot | 对话或对峙的互切 |
| 视线匹配 | eyeline match | 视线方向衔接 |
| 威亚 | wire-work / wire-fu | 吊钢丝拍飞跃 |
| 亮相 | striking a pose | 戏曲中人物定格造型 |
| 锣鼓经 | (Peking opera) percussion patterns | 京剧打击乐节奏型 |
| 武术指导 | action / martial arts choreographer | — |

## 声音
| 中文 | English | 释义 |
|---|---|---|
| 持续低音 | drone | 张力铺底 |
| 上升音 | riser | 推向 hit 的上升音效 |
| 重击 | hit / impact | 强调重要时刻 |
| 低频下潜 | sub drop | hit 之后的低频下坠 |
